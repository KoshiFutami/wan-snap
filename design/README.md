# Wan-Snap Design System

愛犬ファッションスナップ・コミュニティ **Wan-Snap（ワンスナップ）** の公式デザインシステム。
モバイル / PC 両面の UI を、温かみのあるナチュラルトーンと写真ファーストのエディトリアル感で統一します。

## 製品コンセプト

犬種別オーナー向けの「ファッションスナップ＆コミュニティ」。
飼い主が愛犬に服や首輪を着せた写真を投稿し、他のオーナーが **サイズ感 / コーディネート** を参考にできるサービス。デザインの美しさを大事にする愛犬家がターゲット。

主な機能：
- 犬種・体重・カラーで絞り込めるタイムライン
- 写真上のアイテムタグ（ブランド・サイズ・着用感）
- 愛犬プロフィール（成長記録・サイズ履歴）
- 通知 / フォロー / コメント / 保存

## CONTENT FUNDAMENTALS

### トーン
- **温かい・親しみやすい・大人っぽい**（子供っぽさを排除）。落ち着いた愛犬家コミュニティ。
- 句点「。」をブランドアクセントとして使う。例: `Bigger canvas, same warmth.` `愛犬の今日の一枚を、世界へ。`
- カジュアル過ぎず、丁寧過ぎない。「〜です/ます」と動詞止めをバランス。

### 言語
- 主言語は **日本語**。製品名 `Wan-Snap` は英字のまま、付記する場合は「ワンスナップ」とカナ。
- 数字は半角＋等幅フォント (JetBrains Mono)。例: `9.5kg`, `1,284件`, `+18%`
- ハッシュタグや @ メンションは小文字英数 + アンダースコア。`@koushi_to_ema`

### 文字のクセ
- 名前と種別は **中黒「·」** で繋ぐ。例: `柴犬・赤`, `Wan·Snap`
- 比喩や絵文字は控えめ。1投稿に最大1〜2個（🌿✨💚 など自然系）。
- ボタンは動詞 + 矢印で誘導。例: `スナップを表示 →`, `次へ · 愛犬の情報 →`

### コピー例
- ヒーロー: 「愛犬の今日の一枚を、世界へ。」
- セクション見出し: 「今日のスナップ。」「これまでのスナップ」「マイわんたち」
- 空状態（未実装の場合は）: 「まだスナップがありません。」
- 検索プレースホルダー: 「犬種・ブランド・タグで検索」
- 統計サブ: 「+184 今週」「標準体型」「同犬種平均値内」

## VISUAL FOUNDATIONS

### カラー
- **ウォームクリーム** をベースに、**インクブラック** で文字、**テラコッタ** と **深緑** をアクセント。
- 彩度は控えめ。グラデーションは原則使わない（ヒーローカバーで極淡なグラデのみ可）。
- 例外: 犬の写真自体は鮮やかでOK。UI は写真を引き立てる脇役に徹する。

### タイポ
- **見出し**: Noto Serif JP (500/600) — 編集的でやや細身、letter-spacing は -0.01〜-0.025em。
- **本文**: Zen Kaku Gothic New (400/500/600) — クセのない和文ゴシック。
- **数値**: JetBrains Mono (400/500) — タビュラー、kg/cm の前後で。
- 巨大見出しでは **句点をテラコッタに着色** してリズムを作る。

### 背景・テクスチャ
- 単色 (`cream` または `cream-soft`) 中心。テクスチャ・パターン・写真の全面背景は **使わない**。
- カードは `paper` 色 + 1px hairline (`rgba(31,26,20,0.08)`) で軽く区切る。
- カバーや空エリアにのみ淡いグラデーション (`terracotta-soft → cream`) を許可。

### アニメーション
- 動きは控えめ。**画面遷移**: 200–280ms、`cubic-bezier(0.22, 1, 0.36, 1)`（gentle ease-out）。
- 透明度 + 8px上方向のスライド。バウンスや過剰な anim は使わない。

### Hover / Press
- **Hover**: 不透明度 95%、または背景に hairline を1段濃く（`rgba(31,26,20,0.04)` の overlay）。
- **Press / Active**: わずかに sink（`scale(0.985)`）。

### ボーダー・カード
- 共通ラジアス: **8 / 10 / 12 / 14 / 18 / 22 / 999 (pill)** の6段。
- カード: `radius: 14–18px`, hairline 1px, ノーシャドウ または `0 4px 14px rgba(31,26,20,0.06)`。
- モーダル: `radius: 18px`, ヘビーシャドウ `0 30px 80px rgba(0,0,0,0.4)`。

### ガラス / ブラー
- ナビ越しの数字バッジ、写真上のオーバーレイ pill にのみ `backdrop-filter: blur(8–12px)` を使う。
- 過度な glass UI は禁止。

### レイアウト
- **モバイル**: 390 × 844 (iPhone 14 Pro)。左右余白 16–20px。タブバー 84px。
- **PC**: 1440 × 900。サイドバー 220px + 流体コンテンツ + 右レール 300px。ガター 40px。

### 写真
- アスペクト比: `4 / 5` (縦) または `1 / 1` (正方形)。横長は避ける（犬の縦長プロポーションを活かす）。
- アイテムタグは **白dot + 細い白線 + 白カード** の編集的スタイル。

## ICONOGRAPHY

- すべての UI アイコンは **インラインSVG**、stroke 1.5–1.8px、`stroke-linecap: round`。
- セット: ホーム / 検索 / お知らせ / プロフィール / 戻る / 閉じる / 共有 / ハート / コメント / ブックマーク / フィルター / 体重 / 肉球 / グリッド / タグ / プラス。
- 肉球（paw）はブランドアイコンで、テラコッタで塗る場合あり。
- **絵文字** は通常UIで使わない。例外: コメント本文（ユーザー入力）と、検索カテゴリラベルの装飾用（👕🎀🦮 等）のみ。
- 数値バッジは円形 + 1色（terracotta = いいね / forest = コメント / ochre = フォロー）。

詳細は `assets/icons/` と `preview/icons.html` 参照。
