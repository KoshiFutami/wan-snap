# /review

マージ前のコードレビューを実施します。

## チェック項目

### 正しさ
- [ ] 機能が仕様通りに動作する
- [ ] エッジケース・バリデーションが適切
- [ ] DDD の境界が崩れていない（ドメイン層にインフラ依存がない）

### セキュリティ
- [ ] 認証・認可が漏れていない
- [ ] SQL インジェクション・XSS 等の脆弱性がない
- [ ] 機密情報がハードコードされていない

### 品質
- [ ] `pnpm typecheck` がパスする
- [ ] `pnpm lint` がパスする
- [ ] 不要な console.log・TODO が残っていない
- [ ] コメントは「なぜ」を説明しているか（「何を」は書かない）

### Docker
- [ ] `docker compose up` で正常に起動する
- [ ] DB マイグレーションが正しく適用される
