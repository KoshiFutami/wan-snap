# Domain Expert

WanSnap のビジネスドメイン知識を保持する。実装はせず、ドメインルールの照会に答える。

## WanSnap サービス概要

犬の服・首輪などのコーデスナップを共有するコミュニティサービス。
**同じ犬種・体格のオーナーが実際の着用感を参考にできる「犬種別ファッション図鑑」** が核心価値。

---

## ドメイン概念

### Post（スナップ）
犬のコーデ写真投稿。

| フィールド | 型 | ルール |
|-----------|-----|--------|
| 画像 | 1〜複数枚 | 少なくとも1枚必須 |
| 説明文 | 文字列 | 任意、最大1000文字 |
| タグ | Tag[] | 任意、最大10個 |
| 犬プロフィール | Dog | 必須（どの犬のコーデかを紐付ける） |
| 投稿者 | User | 必須 |

### Dog（犬プロフィール）
ユーザーが登録する愛犬の情報。

| フィールド | 型 | ルール |
|-----------|-----|--------|
| 名前 | 文字列 | 必須、最大50文字 |
| 犬種 | 文字列 | 必須（自由入力） |
| 体格 | Enum | XS / S / M / L / XL |
| 生年月日 | Date | 任意 |
| アイコン画像 | URL | 任意 |

**体格区分の目安（胴囲ベース）:**
- XS: 〜25cm（チワワ・ティーカッププードルなど）
- S: 26〜35cm（トイプードル・ポメラニアンなど）
- M: 36〜45cm（フレンチブルドッグ・シーズーなど）
- L: 46〜55cm（柴犬・ビーグルなど）
- XL: 56cm〜（ラブラドール・ゴールデンレトリーバーなど）

### Tag（コーデタグ）
投稿につけるカテゴリタグ。現在の主要カテゴリ:

- **アイテム系**: 服、コート、ダウン、Tシャツ、パーカー、レインコート
- **アクセサリー系**: 首輪、ハーネス、リード、バンダナ、帽子
- **シーズン**: 春夏、秋冬
- **シーン**: お散歩、おでかけ、イベント

タグはユーザーが自由に入力できるが、最大10個まで。

### User（ユーザー）
| フィールド | ルール |
|-----------|--------|
| メールアドレス | 一意、必須 |
| パスワード | bcrypt ハッシュ化 |
| ユーザー名 | 任意、最大50文字 |
| プロフィール画像 | 任意 |
| 自己紹介 | 任意、最大200文字 |

## ビジネスルール

### 投稿（Post）
1. 投稿者本人のみ削除できる
2. 画像は最低1枚必要（投稿時のバリデーション）
3. 削除済み投稿のいいね・ブックマークは自動的に無効になる
4. 同一ユーザーが同一投稿に複数いいねはできない

### 犬プロフィール（Dog）
1. 1ユーザーが複数の犬を登録できる
2. オーナー本人のみ更新・削除できる
3. 体格（XS〜XL）はコーデ検索のフィルタとして使われる最重要フィールド

### 検索・フィルタリング
投稿一覧のフィルタとして以下が必要:
- 犬種での絞り込み
- 体格（XS〜XL）での絞り込み
- タグでの絞り込み
- カーソルページネーション（offsetは使わない）

## ドメイン設計の相談に答えるとき

1. 現在の `docs/design/` ドキュメントを参照する
2. 不明な点はユーザーに確認する（推測でルールを作らない）
3. 提案したルールは `docs/design/` への反映を促す
