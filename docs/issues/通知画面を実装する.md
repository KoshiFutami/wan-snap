# 通知画面を実装する（/notifications）

## 概要

デザインファイル（`design/screen-misc.jsx`）に「お知らせ」画面が定義されているが、フロントエンドに `/notifications` ルートが存在しない。
また、BottomNav の4番目のタブがデザインでは「お知らせ（🔔）」になっているが、現在は「保存（🔖）」として機能している。

## デザイン仕様（`design/screen-misc.jsx` - NotificationsScreen）

- ページ上部: 「お知らせ · 8 new」「Notifications · 8 new」テキスト
- タブ切り替え: **すべて / 未読 / いいね / コメント / フォロー**
- 通知行の要素:
  - ユーザーアバター + アクション種別アイコン（いいね=テラコッタ / コメント=フォレスト / フォロー=オーカー）
  - テキスト「{ユーザー名} が {アクション} しました」+ 時刻
  - 投稿サムネイル（いいね・コメント通知の場合）
  - アクションボタン（フォロー通知の場合: 「フォローする」）
- セクション見出し: **今日 / 今週 / 今月**

## 受け入れ条件

- [ ] `/notifications` ページを実装する（デザイン通りのUI）
- [ ] BottomNav の4番目タブを「お知らせ（ベルアイコン）」に変更し `/notifications` へ遷移させる
- [ ] いいね・コメント・フォロー通知を一覧表示できる
- [ ] タブで種別絞り込みができる（すべて / 未読 / いいね / コメント / フォロー）
- [ ] 未読数バッジをタブ上に表示できる
- [ ] 通知行をタップすると対象リソース（投稿詳細・ユーザープロフィール等）へ遷移できる
- [ ] フォロー通知行のボタンからフォロー操作できる

## 技術メモ

- バックエンドに `GET /api/v1/notifications` エンドポイントが必要
- 通知レコード: 種別（like/comment/follow）、送信者ID、対象リソースID、既読フラグ、作成日時
- 既読処理: 画面表示時に一括既読 or 個別既読
- 依存: コメント機能（コメント機能ISSUE・未作成）、フォロー機能（フォロー機能ISSUE・未作成）、いいね機能
