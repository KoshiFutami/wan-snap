# フォロー/フォロワー機能を実装する

## 概要

デザインファイルの複数の画面にフォロー/フォロワー機能が定義されているが、バックエンド・フロントエンドともに未実装。
現在、マイプロフィール画面のフォロワー数・フォロー中数は「-」と表示されている。

## デザイン仕様（複数画面）

- **マイわん画面**（`screen-user.jsx` - MyProfileScreen）:
  - 統計行: 投稿数 / **フォロワー 1.2k** / **フォロー中 284**
- **他ユーザー画面**（`screen-user.jsx` - OtherProfileScreen）:
  - アクションボタン: 「**フォローする**」（タップ後: 「フォロー中」）
  - 統計行: フォロワー / フォロー中
- **投稿詳細画面**（`screen-detail.jsx` - DetailScreen）:
  - オーナー行右端に「**フォロー**」ボタン
- **ホームフィード**（`screen-home.jsx` - HomeScreen）:
  - フィルタチップ: 「**フォロー中**」（フォロー中のユーザーの投稿のみ表示）
- **PC ホーム**（`pc-screen-feed.jsx`）:
  - 右サイドバー「おすすめオーナー」の「**フォロー**」ボタン

## 受け入れ条件

- [ ] `POST /api/v1/users/:id/follow` — フォローする
- [ ] `DELETE /api/v1/users/:id/follow` — フォロー解除する
- [ ] `GET /api/v1/users/:id/followers` — フォロワー一覧
- [ ] `GET /api/v1/users/:id/following` — フォロー中一覧
- [ ] マイプロフィール画面にフォロワー数・フォロー中数を表示する
- [ ] 他ユーザー画面に「フォローする / フォロー中」ボタンを実装する（ログイン時のみ表示）
- [ ] 投稿詳細画面のオーナー行にフォローボタンを実装する
- [ ] ホームフィードの「フォロー中」チップで絞り込めるようにする

## 技術メモ

- `follows` テーブル: `follower_id`（FK: users）/ `following_id`（FK: users）/ `created_at`
- 複合ユニーク制約: `(follower_id, following_id)`
- フォロー数は `users` テーブルに非正規化カウンタを持つか、都度集計する
- 認証必須（自分自身はフォロー不可）
