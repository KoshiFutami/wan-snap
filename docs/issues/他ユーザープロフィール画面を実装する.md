# 他ユーザープロフィール画面を実装する（/users/[id]）

## 概要

デザインファイル（`design/screen-user.jsx`）に他ユーザーのプロフィール画面（OtherProfileScreen）が定義されているが、フロントエンドに `/users/[id]` ルートが存在しない。
投稿詳細画面のオーナー情報をタップすると他ユーザープロフィールへ遷移するため、この画面が必要。

## デザイン仕様（`design/screen-user.jsx` - OtherProfileScreen）

- ヘッダー: `@{ユーザーID}` タイトル付き AppBar
- プロフィールセクション:
  - アバター写真（76×76）
  - 統計: **投稿数 / フォロワー / フォロー中**
  - 表示名・自己紹介文
  - アクションボタン行: 「フォローする」「メッセージ」「⋯（その他）」
- 愛犬セクション: 「{ユーザー名}の愛犬」＋ DogCard 一覧
- タブ切り替え: **スナップ / サイズ感 / ブランド**
- スナップグリッド: 3カラムグリッド（タップで投稿詳細へ）

## 受け入れ条件

- [ ] `/users/[id]` ページを実装する（デザイン通りのUI）
- [ ] 投稿詳細画面のオーナー情報（アバター + 犬名）をタップするとこのページへ遷移する
- [ ] プロフィール情報（アバター・表示名・統計・bio）を表示できる
- [ ] そのユーザーの愛犬一覧を表示できる（`/dogs/[id]` へのリンク付き）
- [ ] 投稿グリッドを3カラムで表示できる
- [ ] 「フォローする / フォロー済み」ボタンを表示し操作できる
- [ ] ログイン中の自分のプロフィールを表示しようとした場合は `/profile` へリダイレクトする
- [ ] サイズ感タブ・ブランドタブはフェーズ2で実装（初期は投稿タブのみでよい）

## 技術メモ

- `GET /api/v1/users/:id` エンドポイントでユーザー情報を取得
- `GET /api/v1/dogs?userId=:id` で他ユーザーの犬一覧を取得
- `GET /api/v1/posts?authorId=:id` で他ユーザーの投稿一覧を取得
- 依存: フォロー機能（#フォロー）
