# コメント機能を実装する

## 概要

デザインファイルの複数の画面にコメント機能の UI が定義されているが、バックエンド・フロントエンドともに未実装。
フィードカード・投稿詳細のコメントアイコンには件数（34）が表示されているが、現在の実装ではコメント件数すら表示されていない。

## デザイン仕様（複数画面）

- **ホームフィード**（`screen-home.jsx` - FeedCard）:
  - フッターアクション行: ❤️ 428 / **💬 34** / 📤 / 🔖 62
- **投稿詳細画面**（`screen-detail.jsx` - DetailScreen）:
  - アクションバー: ❤️ 428（赤塗り） / **💬 34**（コメント件数）
- **通知画面**（`screen-misc.jsx` - NotificationsScreen）:
  - コメント通知行: 「{ユーザー名} がコメントしました：「{コメント本文}」」
- **PC ホーム**（`pc-screen-feed.jsx`）:
  - カードフッター: ❤️ / **💬 34** / 📤

## 受け入れ条件

- [ ] `GET /api/v1/posts/:id/comments` — コメント一覧（カーソルページネーション）
- [ ] `POST /api/v1/posts/:id/comments` — コメント投稿（認証必須）
- [ ] `DELETE /api/v1/comments/:id` — コメント削除（投稿者本人のみ）
- [ ] 投稿詳細画面にコメント件数を表示する
- [ ] 投稿詳細画面にコメント一覧と入力フォームを実装する
- [ ] フィードカードにコメント件数を表示する
- [ ] コメント投稿時に通知を生成する（通知機能と連携）

## 技術メモ

- `comments` テーブル: `id` / `post_id`（FK: posts）/ `author_id`（FK: users）/ `body`（最大500文字）/ `created_at`
- コメント件数は `posts` テーブルに非正規化カウンタを持つか、都度集計する
- 返信（スレッド）は将来拡張（フェーズ2以降）
- 認証必須でコメント投稿
