# 0005. AWS インフラ管理に CDK を採用

- **ステータス:** Accepted
- **日付:** 2026-05-15

## 背景

Wan Snap のアプリケーションコードとインフラ定義が分離されており、インフラ変更の履歴やレビューを同じリポジトリで一元管理できていない。

## 判断

このリポジトリに `apps/cdk` を追加し、AWS インフラは AWS CDK（TypeScript）で管理する。

## 理由

TypeScript ベースで既存モノレポの技術スタックと整合性が高く、アプリケーションコードと同じ変更フロー（PR/レビュー/履歴管理）で運用できるため。
Terraform など別ツールも選択肢だが、新しい言語・運用体系の導入コストを避けるため今回は採用しない。

## 結果

インフラ変更をコードとしてレビュー可能になる一方、CDK の bootstrap/deploy 手順と AWS 認証情報の管理が新たに必要となる。
